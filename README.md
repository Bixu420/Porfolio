## 🛡 GoodUSB – BadUSB Detection Tool (Python)

Developed a Windows-based defensive tool aimed at reducing the risk of BadUSB-style attacks.

Core concept:
- Detect anomalous keyboard input patterns (typing speed, burst behavior, shortcut sequences)
- Trigger defensive response mechanisms
- Log suspicious input activity

Features:
- Input behavior anomaly detection
- Configurable thresholds
- Audit vs enforcement mode
- Windows system interaction
- Packaged using PyInstaller

Technologies: Python, Windows API, PyAutoGUI, pynput, system hooks
